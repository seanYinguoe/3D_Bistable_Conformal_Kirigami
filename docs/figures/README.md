# Figure sources

- `workflow-process.png`: the authors' original design-process figure corresponding to Fig. 6 of Ying & Dias, *Instability-induced bistable shape-morphing kirigami structures*, [arXiv:2607.26941v1](https://arxiv.org/abs/2607.26941). Rendered from the original vector PDF in the earlier documentation pass without altering its data, labels or geometry. Manuscript under review.
- `surface-example.png`: generated from the default `main_surface` quarter-dome run during this cleanup. The figure shows a candidate pattern; 12 interior assignments miss the configured strain tolerance.
- `energy-example.png`: generated by `main_unit_energy` with `unit_config` defaults. Both curves use the reduced HBM model and are normalised separately. This is not a reproduction of a finite-element validation figure.

Settings and numerical qualifications are recorded in `../validation.md` and `../workflow.md`.
