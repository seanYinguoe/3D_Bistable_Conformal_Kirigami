# Figure sources

Research figures from Ying & Dias, [*Instability-induced bistable shape-morphing kirigami structures*](https://arxiv.org/abs/2607.26941), arXiv:2607.26941v1, including supplementary information. Manuscript under review.

- `workflow-process.png`: authors' original figure corresponding to main Fig. 6.
- `deployment-energy.png`: authors' original figure corresponding to main Fig. 2, including actual HBM and finite-element results.
- `smooth-setting.png`: supplementary Fig. S6.
- `discrete-setting.png`: supplementary Fig. S7.

These images were rendered from the original vector PDFs without modifying geometry, labels or data.

- `conformal-example.png`: newly generated by `demo_conformal_mesh('quarter_dome')` using the bundled target mesh and UV map.
- `energy-example.png`: newly generated by `demo_unit_energy`, using its recorded illustrative parameters. It is not a reproduction of the published validation curves.
